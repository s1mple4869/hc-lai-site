## 4. 规范增补（合并进 `chart-language-spec-v1.md`，升为 v1.1）

### 4.1 新增条款

| 章节 | 条款 |
|---|---|
| 2. 容器 | **渲染宽度不得超过源图宽度。** 源图 < 880 的图按原始尺寸居中显示，禁止放大。实现：`min(880px, var(--fig-native-w), 100vw - 3rem)` |
| 2. 容器 | **白卡给自建组件与 SVG；截图只给圆角 12px + 1px ink/10 细边**，不加白色内衬。两类东西两种待遇，各自内部统一 |
| 6. 分诊 | **代码截图一律重做为真代码块**（可选中、可搜索、永远锐利）。深色代码块规格：底 `#1C1B17` / 正文 `#F2EFE9` / 注释 `#6B6862` / 圆角 12px / 无边框。**不引入语法高亮库**（会带进 5–8 种颜色，违反色彩纪律） |
| 6. 交互 | **Lightbox 只给图片（截图、SVG），不给 HTML 组件。** 组件本身是真文字、会响应式重排，不需要点击放大 |
| 1. 色彩 | **改了底色的列/行，必须复查分隔线是否仍然贯通、颜色是否一致。** 半透明分隔线压在不同底色上会呈现不同色值，应改用**预先算好的不透明色** |
| 3. 排印 | 两张并置的对照表，**共有列必须对齐同一位置**（如 Priority 均左置、cream 列均右置同宽），差异列居中。呈现层可重排列序，原始列序保留在数据源中 |
| 5. 数据 | 图表中的**每一条内容都必须能追溯到数据源**。若正文与数据源不一致（如 MDX 里存在数据源中没有的条目），先报告，由作者决定删或补 |

### 4.2 踩坑档案新增

| # | 坑 | 处方 |
|---|---|---|
| 13 | Tailwind 类名用模板字符串拼接会静默失效 | 静态扫描器看不到动态拼出的 class 名。**必须写成字面量静态字符串** |
| 14 | Notion 导出的 `.csv` 可能实际是 Excel 二进制（zip） | 读前先验格式；用 `openpyxl` 转成真正的纯文本 CSV |
| 15 | `subset-fonts.mjs` 只扫 `content/`/`app/` 的 `.mdx/.tsx/.ts` | **数据文件（CSV）里的中文从未进过字体子集**。已把 `design-refs/*.csv` 纳入扫描；任何新增数据源都要确认在扫描范围内 |
| 16 | 同一组件里叠了两套分隔线实现（`box-shadow` + `background-image`） | 半透明线叠加会变深。一处只留一套实现 |
| 17 | CSV 的 Windows 换行 `\r` 残留 | `split('\n')` 后末列名带 `\r`，匹配失败导致整列空白。读取时统一处理 |

### 4.3 工作方法新增

- **回退时区分「实验功能」与「顺手捡到的正交修复」**，后者要在回退 brief 里点名保留
  （吸附功能回退时误伤了字体竞态修复，导致该 bug 复活）
- **病因描述里的数值写错 ≠ 修法错。** 判断要不要返工，看这个数**有没有进代码**
- **给 Claude Code 的 brief 里，凡是顾问转录的数据都必须标注"可能有误，以实际数据源为准"**，
  并要求它核对后报告差异，不许照抄 brief
- **图表类型分流**：数据图（stat / 对比条 / 表格）走 Figma 比稿 → 换算规格 → HTML 组件；
  结构图（流程 / 机制）直接出 SVG。后者更快、无转译损耗、不吃 Figma 额度

## 6. 给下一段对话的提醒

1. **顾问看不到 Claude Code 的界面**，它的所有产出都要由作者转贴
2. **数字要绝对值，不要只给百分比**（"+230%" 无法判断，"181KB" 可以）
3. **每份 brief 自带可量化验收指标**，要求前后对照
4. **一次一个决策，一次只动一个数**
5. **视觉判断终审权归作者**，顾问给的数值都是初值不是圣旨
6. **参照系也有做不到的事** —— Anthropic 的 hero 也不保证每次滚动都精确居中；
   追一个原版都没做到的目标，是在浪费工程预算
